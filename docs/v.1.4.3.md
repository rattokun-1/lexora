# コトミア v1.4.3

## デザインと操作性

- 学習画面の背景をコトミアのアイボリー／深い青緑の単一テーマに統一。
- 学習画面の重いガラス合成をやめ、カード遷移とスワイプの描画負荷を軽減。
- 旧バイオレット系の学習ショートカットをコトミアの青緑へ統一。
- プロフィールとアカウント設定の幅、スクロール、ボタンサイズ、スマートフォン表示を調整。
- 対戦待機画面にプロフィール画像を表示し、未ログイン時はパスキー画面へ直接移動できる導線を追加。
- モーダルの背景ぼかしとアニメーションを軽量化。動きを減らすOS設定は従来どおり対応。

保存データ、認証、パスキー、SupabaseのDB/RPC、学習の終了条件・出題条件は変更しません。
