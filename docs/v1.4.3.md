# コトミア v1.4.3

Issue #9対応。配布用ZIPとPRを作成し、本番サーバーとSupabaseの設定は変更しません。

## 変更

- 学習はネイティブの縦スクロールとスナップで1問ずつ表示。前のカードは閲覧のみ、次へのスクロールは未回答のスキップとして扱い、採点・報酬・ステージ完了には加算しません。
- ステージは既存のcourseOrder・lessonProgress・completedLessonsを引き継ぎ、完了したステージと次の1つだけを開放。ステージ内の新出語は引き続き1回最大5語です。
- 旅のUI・操作・導線・3Dエンジンの読み込みを廃止。旧保存データのadventureフィールドは互換性のため保持します。旧マップ関連コードは履歴検証用にリポジトリに残しますが、配布物から除外します。
- 直近7日間の対戦ベスト正解数ランキング。終了した対戦のサーバー採点を使い、同点同順位、上位100件、仮名表示。メール・写真・ユーザーID・学習履歴を公開しません。
- 学習コインでバッジを集める「星のアトリエ」を独立実装。1回100コイン・5回500コイン。10回目は未所持バッジ確定、全所持後の重複はコインへ。以前の所持品・コイン・抽選回数と履歴は維持します。
- 軽量な背景の動きと、装備バッジによる背景色の変化。OSの動きを減らす設定に対応。
- 意味選択で正解を先頭に固定していた不具合を修正。英単語選択で意味の配列を採点に使っていた不具合と、選択肢の再描画時の並び替わりも修正。

## 任意の適用手順（この作業では未実行）

1. 既存の静的ファイルとDBをバックアップ。
2. 既存DBにv1.4.0までの移行が適用されていることを確認。
3. ランキングを有効にする場合は、Supabase SQL Editorで `setup/202611040001_leaderboard.sql` を実行（ソースではsupabase/migrations/内）。実行権限はログイン済みユーザーのみです。
4. ZIP直下のindex.html・src/などを既存の静的公開ディレクトリへ配置。setup/は管理者向けの資料で配信不要です。旧world-map等を消す場合は、公開ディレクトリを確認して個別に削除してください。
5. バージョン付きCSS/JS、ステージ、スクロール、ガチャ、ランキングを確認。

DB未設定時はランキング画面に準備中の案内を表示します。既存ログイン・学習・対戦RPCに変更はありません。新規DBには過去の移行も必要です。

対戦参加者の少ない環境では実ユーザー2人での試験が必要です。クライアント内のコイン・所持品は既存と同じ保存方式で、不正対策済みの課金通貨ではありません。
