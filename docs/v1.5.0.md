# コトミア v1.5.0

Lexoraの表示名をコトミアへ変更し、学習開始までの操作と対戦画面を刷新します。

- 青緑・アイボリー・金の配色。対戦相手はコーラルで区別。
- ホーム上部に大きな学習開始ボタン。旅のプレビューと対戦入口。
- スクロール方向・旅の移動に合わせて縮むガラス調ナビ。44px以上のタップ領域、動きを減らすOS設定に対応。
- プロフィールは上部のカードに集約。詳細はアカウント設定内へ。
- 対戦はマッチング、開始カウントダウン、得点、残り時間、結果を整理。サーバーの開始・終了時刻と採点を維持。
- 登録と復旧のOTPメールをインラインCSS・テーブル構成で更新。トークン差し込みと本番URLを維持。

既存の保存キー・DB・認証のRP ID・GitHub URLは互換性のため維持します。DB移行は不要です。SupabaseのConfirm sign up/Magic link or OTPの本文にはsupabase/templates/email-otp.htmlを設定します。差出人名とパスキー表示名はコトミアへ変更し、SMTP認証情報は維持します。

検査：構文・秘密情報パターン検査、34件のテスト、静的ビルド、CIのPostgreSQL統合検査。対戦画面の各状態はモック応答と自動テストで検査し、実ユーザー2人の同時対戦試験は別途必要です。
