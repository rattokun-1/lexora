# 学習と探索のRPG

## 体験

斜め上から見下ろすローポリ3D。県・市・固定レッスン足場は使わず、草原、森、渓谷、遺跡、雪山が連続する。主人公は人間と同じ耳、青緑の髪、藍色の短いマント、琥珀色の瞳、光る石の飾りを持つ固定の旅人。戦闘、素材集め、操作精度を求める課題は設けない。

PCはWASD・矢印キーで歩き、Eで近くの対象を調べる。スマホは左の仮想スティックと右のアクションボタン。カメラは主人公に追従。人物、石碑、焚き火に近づいても勝手に学習を開始せず、短い会話で「学習する」「あとで」を選ぶ。

画面上の「今日の学習」は移動を省略して直接始められる。ホームからの学習も探索の進行に加算する。ゲームのHPが0でも学習を妨げない。

## 動的な出題

既存のTangoScheduler/TangoPlacementによる復習優先、初見の確認→意味選択→想起→入力を使う。新出は3〜5語。出題語は訪問先に固定せず、診断結果・普段の正誤・復習期限・学習の進行から組み立てる。再出題は既存の上限を維持する。

## 進行と保存

adventure-data.js はWebGLに依存しない進行・当たり判定のルール。adventure に completed、lastLessonId、position、chests を保存し、既存のローカル保存とクラウド同期に含める。既存の単語履歴は維持する。

全初回出題語への回答が済んだレッスンを1回として数える。全問正解は要求しない。スキップや途中終了、自動送りは解放回数に加算しない。同じセッションの二重加算を防ぐ。

解放条件は累計0/1/3/5/8回。橋の欠けた板と灯が戻り、次の地域へ歩けるようになる。地形外、川の橋以外、未解放の境界、木や建物への侵入を防ぐ。移動は小刻みな衝突判定で、低フレームレートでも境界をすり抜けない。

宝箱は5か所。学習を挟まず、到達した地域で寄り道として回収できる。近接・地域解放・未受取を検証し、二重受取を防ぐ。

## 軽量化と配信

Three.js r170（MIT）を同梱。world-loader.js で見える範囲に近づくまで3Dを読み込まない。描画は移動・カメラ追従・操作・リサイズ時だけ、最大30fps。静止時、非表示、画面外では停止する。近隣地域の小物だけを描画し、モデルと材質はインスタンス化して共有。画面遷移時にGPU資源とイベントを解放する。

配信用バンドルの再生成:

    npm exec --yes --package=esbuild@0.25.0 -- esbuild src/world-map.js --bundle --minify --format=esm --target=es2020 --legal-comments=linked --outfile=src/world-map.bundle.js

変更後はbundleとバージョン付きURLも更新する。ライセンスは src/vendor/three.LICENSE とバンドルのLEGALファイルに保持。

テスト:

    node --test tests/adventure.test.cjs tests/world-render.test.cjs tests/learning.test.cjs tests/map.test.cjs

map.test.cjs は旧マップの保存・報酬ルールの互換性を検証する。新しい進行・当たり判定は adventure.test.cjs で検証する。
